## Description

This code is designed to optimize the robot picking sequence in a bipartite setting. The objective of the optimization is to minimize the total travel time required for the robot to complete its picking tasks from a set of Gravity Racks and placing tasks to a set of Kit Holders.

In our approach, we develop a combination of heuristic methods, reinforcement learning, and exact optimization algorithm. Specifically, we apply heuristic approaches such as Nearest Neighbor and 2-opt. Also, we implement a Q-Learning method to show how reinforcement learning reflect to these type of problems. Last, we solve the problem using an Exact method, in order to find the optimal solution. 
The reason of using different methods is to experiment with a variety of approaches and evaluate the pros and cons of each according to different instances of the problems. By comparing the results of the objective values and the execution times of each method, we are able to gain insights into their performance and allowing us to evaluate which approach is best for our needs.
